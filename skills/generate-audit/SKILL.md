# generate-audit

Generate structured audit evidence from a governance graph: a compliance evidence package documenting policy coverage, rule enforcement status, and a traceable record for review.

## Trigger

User says something like:
- `/generate-audit`
- "generate audit evidence"
- "create a compliance evidence package"
- "produce audit documentation for my governance graph"

## What This Skill Does

Produces a complete audit evidence package from a compiled governance graph, including:
1. Policy inventory (all rules documented with IDs)
2. Coverage matrix (which policy areas are addressed)
3. Conflict register (from detect-conflicts output, if available)
4. Compliance trace log (from trace-compliance outputs, if available)
5. Executive summary

Designed for compliance reviews (SOC 2, ISO 27001, CMMC, HIPAA, or internal governance audits).

## Step-by-Step Instructions

### Step 1: Load Available Evidence

Check for the following files and load each if present:
- `governance-graph/graph.json` — required
- `governance-graph/analysis.md` — optional
- `governance-graph/conflicts.md` — optional
- `governance-graph/traces/` — directory, collect all trace files

If `graph.json` is missing, ask the user to run `/compile-policy` first.

### Step 2: Build Policy Inventory

List all rules in the graph with:

| Rule ID | Section | Rule Text | Section Level |
|---------|---------|-----------|---------------|

Sort by section hierarchy (top-level sections first, then subsections).

### Step 3: Build Coverage Matrix

Map rules to standard governance domains:

| Domain | Rules Found | Coverage |
|--------|-------------|----------|
| Access Control | <list rule IDs> | COVERED / PARTIAL / MISSING |
| Data Protection | <list rule IDs> | COVERED / PARTIAL / MISSING |
| Audit & Logging | <list rule IDs> | COVERED / PARTIAL / MISSING |
| Incident Response | <list rule IDs> | COVERED / PARTIAL / MISSING |
| Credential Management | <list rule IDs> | COVERED / PARTIAL / MISSING |
| Multi-Agent Coordination | <list rule IDs> | COVERED / PARTIAL / MISSING |
| Rate Limiting / Resource Control | <list rule IDs> | COVERED / PARTIAL / MISSING |

Coverage levels:
- COVERED: 3+ rules in domain
- PARTIAL: 1-2 rules in domain
- MISSING: 0 rules in domain

### Step 4: Compile Conflict Register

If `governance-graph/conflicts.md` exists:
- Summarize critical conflicts with their IDs and status
- Include a column for resolution status (user can fill in: RESOLVED / ACCEPTED / OPEN)

If conflicts file does not exist, note: "Conflict detection has not been run. Run `/detect-conflicts` to populate this section."

### Step 5: Compile Trace Log

If `governance-graph/traces/` contains trace files:
- List each trace with: timestamp, scenario, verdict, rules applied
- Show aggregate verdict counts (PERMITTED N, CONDITIONAL N, PROHIBITED N, AMBIGUOUS N)

### Step 6: Write Executive Summary

```
Governance Audit Evidence Package
══════════════════════════════════════════════════════════
Generated:      <ISO datetime>
Policy Source:  <filename>
Compiler:       memoriant-governance-compiler-skill v1.0.0

Policy Statistics:
  Total Sections:  <N>
  Total Rules:     <N>
  Hierarchy Depth: <N> levels

Coverage Summary:
  Domains Covered:  <N>/7
  Domains Partial:  <N>/7
  Domains Missing:  <N>/7

Conflict Status:
  Critical Conflicts:  <N>
  Warnings:            <N>
  (Run /detect-conflicts for full analysis)

Compliance Traces:
  Traces on record: <N>
  Permitted:        <N>
  Conditional:      <N>
  Prohibited:       <N>
  Ambiguous:        <N>

Auditor Notes:
  This evidence package was generated by an AI governance compiler.
  All rule text is reproduced verbatim from the source policy document.
  Human review is required before treating this as a definitive compliance record.
```

### Step 7: Write Package Files

Write the following to `governance-audit/`:
- `governance-audit/evidence-package.md` — complete audit document
- `governance-audit/policy-inventory.csv` — rule ID, section, text (machine-readable)
- `governance-audit/coverage-matrix.json` — domain coverage in JSON

Print confirmation:
```
Audit evidence package written to governance-audit/
  evidence-package.md
  policy-inventory.csv
  coverage-matrix.json
```

## Output Files

- `governance-audit/evidence-package.md`
- `governance-audit/policy-inventory.csv`
- `governance-audit/coverage-matrix.json`

## Important Note

This skill produces evidence documentation to assist human auditors. It is not a legal compliance authority. All output requires human review and validation.
